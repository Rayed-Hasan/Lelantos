# Lelantos Frontend

A split-screen enterprise interface for Project Lelantos, featuring live AI state synchronization and supervisor reasoning telemetry.

## Tech Stack
- **Framework**: React 19 + Vite + TanStack Router / TanStack Start
- **Styling**: Tailwind CSS, Radix UI Primitives, Lucide Icons
- **Animations**: Framer Motion
- **Backend API Gateway**: FastAPI `/api` proxy

## Local Development
```bash
npm install
npm run dev
```
